## Isak Ejlertsson Kidane

Economics student at Linnaeus University, working where economics meets data —
statistics, and the code needed to get at it.

**Tools:** Python (pandas), R, SQL

### Projects

**[stock-macro-analyzer](https://github.com/Isak-Ejlertsson-Kidane/stock-macro-analyzer)** —
a command-line tool that tests whether a listed company's returns move with the economy
around it. It reports a correlation with a confidence interval and a leave-one-out
robustness check, so a number that cannot be distinguished from zero is reported as
exactly that. Final project for [CS50P](https://cs50.harvard.edu/python/) (HarvardX).
